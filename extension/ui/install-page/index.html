DoDAO Highlighter

A Chrome extension for leaving feedback on docs.dodao.io. You select a sentence on a docs page, highlight it and write a comment about it. The comments are collected so that the docs can be improved from them.

Install it in Chrome

Chrome installs extensions in one click only from the Chrome Web Store. This one is not in the store, so Chrome asks you to load it yourself. It takes about a minute.

  1. Download the extension with the button above, and unzip the file.
  2. Open Chrome's extensions page. A web page is not allowed to open it for you, so copy this address into the address bar:
    chrome://extensions
  3. Turn on Developer mode, with the switch at the top right of that page.
  4. Click Load unpacked, and choose the folder you unzipped.
  5. Click the extension's icon in the toolbar, and sign in with the server URL and your API key. The server URL is:
    {{SERVER_URL}}
    Ask the person who runs the docs for an API key.

Updating it

Download the new version and unzip it over the old folder. Then click the reload arrow on the extension's card in chrome://extensions. Your highlights are kept.
